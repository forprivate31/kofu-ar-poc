# 甲府城AR PoC(プレースホルダー版)セットアップ手順

## これは何か
甲府駅北口 → 甲府市歴史公園(山手御門)へ向かう際に、GPS連動WebARで
「山手御門があった場所に、それらしい大きさの仮の箱」が浮かんで見えるかを
検証するための、最小限のテストページです。

3Dモデルはまだ作り込んでいません(白い壁+黒い屋根の簡易ボックス)。
目的は「AR.jsのGPS連動が、この場所・この距離で実用的に機能するか」を
実地で確認することです。

---

## 1. GitHub Pagesへの公開手順(無料)

1. GitHubアカウントを作成(未作成の場合)
2. 新しいリポジトリを作成(例:`kofu-ar-poc`)
   - Public(公開)リポジトリにする
3. このフォルダの `index.html` をリポジトリ直下にアップロード
   - GitHubの画面上から "Add file" → "Upload files" でドラッグ&ドロップ可能
4. リポジトリの Settings → Pages を開く
5. "Source" を `main` ブランチ / `/ (root)` に設定して Save
6. 数分待つと、`https://(あなたのユーザー名).github.io/kofu-ar-poc/` で公開される
   - AR.jsはHTTPS必須だが、GitHub Pagesは自動でHTTPS対応するため追加設定不要

---

## 2. 現地でのテスト手順(甲府駅北口 → 歴史公園)

1. スマホ(できればiPhoneとAndroid両方)で、上記URLをSafari/Chromeで開く
2. 「ARを開始する」ボタンをタップ
   - カメラ・位置情報の許可ダイアログが出るので、すべて「許可」する
   - iOSはモーションセンサー(方位)の許可も別途出る
3. 画面下部に「山手御門(仮)まで:約◯◯m」という表示が出ることを確認
4. 山手御門の方向(甲府市歴史公園の方角)にスマホを向け、白い箱(仮モデル)が
   カメラ映像に重なって表示されるか確認する

### 確認したいポイント(メモしておくと後で役立ちます)
- 箱が表示されるまでの時間(GPS取得にどれくら
かかるか)
- 箱の表示位置が、実際の山手御門とどれくらいズレているか(左右・距離感)
- 方位センサーの精度(スマホを回した時、箱もちゃんと追従して動くか)
- 電波状況による差(駅前は電波が乱反射しやすいので、複数地点で試すと良い)

---

## 3. 次のステップ(この検証結果をもとに調整)

- ズレが大きい場合:座標の微調整、または `gps-entity-place` の距離減衰設定を調整
- 表示が遅い場合:GPS取得のタイムアウト設定や、初期位置の仮固定を検討
- 精度が実用レベルと判断できたら:仮ボックスを、実測・撮影をもとにした
  Blender製の山手御門3Dモデルに差し替える

---

## 現在設定している仮の座標・寸法

- 山手御門(仮)座標:北緯 35.667226 / 東経 138.570866
  ※甲府市歴史公園の代表地点の座標であり、山手御門建物そのものの正確な
    位置ではない。現地訪問時にスマホのGPSで実際の建物位置を計測し、
    座標を更新することを推奨します。
- 仮ボックスの寸法:幅8m × 奥行き4m × 高さ約8m(屋根含む)
  ※山手渡櫓門の実際のスケール感に基づく暫定値。現地で実測後に補正してください。
